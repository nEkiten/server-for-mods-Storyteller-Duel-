# server-for-mods-Storyteller-Duel-
server for mods "Storyteller Duel"
Как запустить:
[]Установи Python 3.8+
[]Скачай репозиторий и открой папку с сервером
[]Запусти в терминале: [code]python server.py[/code]
[]Сервер поднимется на localhost:5000 (по умолчанию)

В игре укажи IP-адрес сервера в настройках мода + порт 5000
Вам нужно будет заменить "localhost" у "http://localhost:5000" на ваш IP в локальном сервере

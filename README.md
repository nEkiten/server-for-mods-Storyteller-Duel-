# Guide server
Server for mods "Storyteller Duel"

## Как запустить:
- Установи Python 3.8+
- Скачай репозиторий и открой папку с сервером
- Запусти в терминале(cmd): `python server.py`
- Сервер поднимется на localhost:5000 (по умолчанию)

## В игре
Укажи IP-адрес сервера в настройках мода + порт 5000.  
Вам нужно будет заменить "localhost" у "http://localhost:5000" на ваш IP в локальном сервере.

# Guide server
Server for mods "Storyteller Duel"

## How to run:
- Install Python 3.8+
- Download the repository and open the server folder
- Run in terminal: `python server.py`
- Server will start on localhost:5000 (default)

## In game
Specify the server IP address in the mod settings + port 5000.  
You will need to replace "localhost" in "http://localhost:5000" with your local server IP.
